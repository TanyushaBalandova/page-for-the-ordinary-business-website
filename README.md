# Путь работника

Страница сайта АНО «Ресурсный центр «Обычное дело»», посвящённая пути кандидата в мастерские организации: от Дня открытых дверей до трудоустройства.

Проект — чистый HTML/CSS без сборщиков и зависимостей.

## Запуск

Ничего устанавливать не нужно — откройте `index.html` в браузере.

Если браузер блокирует локальные шрифты, запустите простой сервер из папки проекта:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`.

## Структура

```text
├── index.html            # единственная страница
├── css/
│   └── style.css         # все стили: базовые, секции и три медиазапроса
├── js/
│   └── script.js         # скрипты (пока пустой)
├── fonts/                # Ony One: Regular (400) и Medium (500), формат woff
└── images/
    ├── logo.svg          # логотип: шапка, футер и favicon
    ├── main.png          # фото мастерской, 397×315
    ├── main-tablet.webp  # вариант того же фото для планшета, в разметке не используется
    ├── scroll.svg        # стрелка для кнопки «Наверх»
    ├── Vector.svg        # стрелка шага аккордеона
    └── footer/           # иконки соцсетей 32×32: 1 — VK, 2 — Одноклассники, 3 — MAX,
                          # 4 — Дзен, 5 — Telegram, 6 — Rutube
```

## Состав страницы

- **Шапка** — меню из пяти пунктов, логотип с подписью «ОБЫЧНОЕ ДЕЛО», кнопка «Помочь». На экранах уже 1200px меню скрывается, и вместо него появляется кнопка-бургер.
- **Основной блок** — хлебные крошки, заголовок, вступительный текст, аккордеон из 7 шагов, фотография и кнопка «Записаться на день открытых дверей». В конце блока лежит кнопка «Наверх».
- **Футер** — логотип, ссылки меню («Обычное дело», «Ключевые курсы», «Досуг») с кнопкой «Помочь», адреса, телефон, почта, шесть иконок соцсетей, юридические ссылки и копирайт.

Шаги аккордеона:

1. День открытых дверей (ДОД)
2. Пробный день
3. Восемь трудовых проб
4. Учебная стажировка
5. Производственная стажировка
6. Трудоустройство по программе квотирования
7. Увольнение

## Адаптивность

В `css/style.css` три медиазапроса по `max-width`. На узком экране действуют все подходящие блоки сразу: правила для телефона дополняют правила для планшета, а не заменяют их.

| Блок в `style.css` | Ширина экрана |
| ------------------- | ------------- |
| базовые стили | больше 1200px |
| «Версия для планшета» | 1200px и меньше |
| «Версия для узких планшетов» | 768px и меньше |
| «Версия для телефона» | 480px и меньше |

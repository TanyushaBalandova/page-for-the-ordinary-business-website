# Путь работника

Страница сайта АНО «Ресурсный центр «Обычное дело»», посвящённая пути кандидата в мастерские организации: от Дня открытых дверей до трудоустройства.

Проект — чистый HTML/CSS без сборщиков и зависимостей.

## Запуск

Ничего устанавливать не нужно — откройте `index.html` в браузере.

Либо перейдите по ссылке: https://tanyushabalandova.github.io/---/

## Структура

```
├── index.html        # единственная страница
├── css/
│   └── style.css     # все стили
├── js/
│   └── script.js     # скрипты (пока пустой)
├── fonts/            # Ony One (Regular, Medium) в формате woff
└── images/
    ├── logo.svg      # логотип
    ├── main.png      # фото мастерской
    ├── Vector.svg    # иконка раскрытия аккордеона
    └── footer/       # иконки соцсетей (1–6.svg)
```

## Состав страницы

- **Шапка** — меню, логотип, кнопка «Помочь».
- **Основной блок** — хлебные крошки, заголовок, вступительный текст, аккордеон из 7 шагов, фотография и кнопка «Записаться на день открытых дверей».
- **Футер** — логотип, ссылки меню, адреса, контакты, соцсети, юридические ссылки.

Шаги аккордеона:

1. День открытых дверей (ДОД)
2. Пробный день
3. Восемь трудовых проб
4. Учебная стажировка
5. Производственная стажировка
6. Трудоустройство по программе квотирования
7. Увольнение

## Стили

Стили написаны по методологии БЭМ с блоками по секциям (шапка, основной контент, футер).
